# Feature Specification: 账号鉴权与受保护路由

- ID: `001`
- Status: `Verified`
- Created: `2026-10-27`
- Supersedes: `none`

## 问题与目标

Orbit 目前没有账号边界，所有页面和本地数据对任何访问者开放。作为真实业务的基础模块，需要提供最小的邮箱密码账号体系，使应用可以区分未登录访客和已登录用户，并让任务与设置归属于当前账号。

目标：

- 支持邮箱密码注册、登录、退出和会话恢复
- 未登录用户不能访问业务页面
- 已登录用户可以维护自己的显示名称和密码
- 不接第三方登录

## 非目标

- Google / Telegram / Discord 等第三方 OAuth
- 邮箱验证、找回密码、MFA、验证码
- 多角色、团队、组织、权限管理
- 账号注销、数据导出与服务端数据同步
- 生产级服务端部署与数据库设计
- 修改现有任务业务模型

## 用户故事

### User Story 1 - 注册并登录 (Priority: P1)

作为新用户，我可以使用昵称、邮箱和密码创建账号，并在后续访问中登录，以便进入自己的工作台。

**为什么是 P1**：没有可用的注册和登录，账号模块没有业务价值。

**独立验证方式**：在空会话下打开注册页，完成注册后进入总览；退出后使用同一邮箱密码重新登录。

**验收场景**：

1. **Given** 未登录且邮箱未被注册，**When** 提交合法昵称、邮箱、密码和确认密码，**Then** 创建账号、保存会话并进入工作台。
2. **Given** 已注册账号，**When** 在登录页提交正确邮箱密码，**Then** 进入原目标页或总览。
3. **Given** 已注册账号，**When** 提交错误密码，**Then** 停留在登录页并显示可理解的错误，不建立会话。
4. **Given** 注册表单存在空字段、非法邮箱、短密码或两次密码不一致，**When** 提交，**Then** 显示对应字段错误且不发送请求。

### User Story 2 - 受保护访问与退出 (Priority: P1)

作为已登录用户，我可以退出登录；未登录访问业务页时会被引导登录，登录后回到原目标页。

**为什么是 P1**：账号模块必须建立清晰的访问边界。

**独立验证方式**：清除会话后访问 `/tasks`，被重定向到登录页；登录后回到 `/tasks`；退出后再次访问被拦截。

**验收场景**：

1. **Given** 未登录，**When** 访问 `/tasks`，**Then** 跳转到 `/login?redirect=/tasks`，登录成功后回到 `/tasks`。
2. **Given** 已登录，**When** 点击退出，**Then** 清除会话并回到登录页；再次访问业务页被拦截。
3. **Given** 已登录，**When** 刷新页面，**Then** 通过会话恢复继续访问，不要求重新登录。
4. **Given** 会话令牌失效，**When** 任意 API 返回 401，**Then** 清理本地会话并跳转登录。

### User Story 3 - 账号资料与密码 (Priority: P2)

作为已登录用户，我可以在设置页修改显示名称，并在提供当前密码后修改密码。

**为什么是 P2**：基础账号需要最低限度的自助维护能力。

**独立验证方式**：设置页修改名称后刷新仍生效；修改密码后旧密码失效、新密码可登录。

**验收场景**：

1. **Given** 已登录，**When** 提交合法新名称，**Then** 页面和侧边栏立即更新，并在刷新后保留。
2. **Given** 已登录，**When** 提交当前密码和符合规则的新密码，**Then** 更新成功并使旧密码失效。
3. **Given** 当前密码错误，**When** 修改密码，**Then** 显示错误并保持当前会话。

## 功能需求

- **FR-001**：系统必须支持邮箱 + 密码注册和登录。
- **FR-002**：密码长度至少 8 位；注册必须确认密码一致。
- **FR-003**：注册时邮箱必须唯一；重复邮箱必须返回可识别错误。
- **FR-004**：登录成功后必须保存会话，并在刷新时恢复。
- **FR-005**：未登录访问业务路由必须重定向到登录页，并保留原目标地址。
- **FR-006**：退出登录必须清理本地会话并调用后端退出接口（失败也要本地清理）。
- **FR-007**：401 必须触发统一未授权处理。
- **FR-008**：已登录用户必须能修改显示名称和密码。
- **FR-009**：不得接入第三方登录。
- **FR-010**：所有新增界面文案必须同时提供中文和英文。
- **FR-011**：登录/注册页必须支持键盘操作、错误提示和密码显隐切换。
- **FR-012**：本地开发必须可运行；生产环境必须可通过同一 API 契约接入真实后端。

## 边界与异常

- 空字段、非法邮箱、短密码、密码不一致
- 邮箱已注册
- 登录凭据错误
- 令牌缺失、过期、被撤销
- 网络错误、服务不可用
- 修改密码时当前密码错误
- 已有本地任务/主题/语言数据不因账号模块丢失

## 假设

- 账号身份只有 `id`、`name`、`email`，不引入角色系统。
- 显示名称可在 2–40 字符之间修改。
- 会话使用 Bearer token；本地演示存 `localStorage`，生产应改用更安全的 Cookie 方案。
- 任务数据仍保存在浏览器本地；本功能只提供账号边界，不做多设备同步。

## 待澄清问题
